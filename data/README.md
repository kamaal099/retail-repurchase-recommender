# Dataset (not included)

Download the real **Online Retail II** dataset (UCI, CC BY 4.0) and place the file in this folder:

- UCI page: https://archive.ics.uci.edu/dataset/502/online+retail+ii  (Download button, ~43 MB zip)
- Unzip so that `online_retail_II.xlsx` sits directly in `data/`
- Kaggle mirror (CSV version, needs a free login): search "Online Retail II UCI" by mashlyn

The loader accepts either `.xlsx` (both sheets are read and de-duplicated) or `.csv`.
